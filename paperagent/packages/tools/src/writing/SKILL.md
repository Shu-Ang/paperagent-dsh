# 论文写作工作流

当用户需要起草或润色现有 LaTeX 手稿、从本地归档的 PaperAgent 论文添加引用，或进行最小 LaTeX 修复时使用此 Skill。它负责协调 PaperAgent 证据与参考文献记录，以及 DSH 工作区文件工具；不负责拥有、替换或创建用户的 LaTeX 模板或参考文献后端。

## 范围与模式

- **draft**：将请求的章节或段落写入用户指定的 `.tex` 文件。
- **polish**：在保留技术事实和 LaTeX 结构的前提下，改进语言、学术结构或双语技术表述。
- **cite**：将一个或多个已验证的本地论文参考文献添加到现有 `.bib`，然后在用户指定的正文位置插入对应的 LaTeX 引用。
- **latex-fix**：诊断编译、引用、公式、表格或浮动体问题，并进行最小且安全的修改。

只在当前 DSH 工作区内操作。任何修改前，使用 DSH 文件读取工具检查目标 `.tex`、足够的上下文、（必要时）主文档以及现有构建说明。用户必须指定目标 `.tex` 文件或明确的目标段落。进行参考文献编辑时，用户必须指定 `.bib` 文件；或者主文档中必须恰好存在一个 `\bibliography{...}` 或 `\addbibresource{...}` 目标。如果目标不明确或不存在，应询问用户；不要创建新的参考文献文件、切换引用后端或重写模板。

## 证据优先的写作

1. 对本地论文相关结论，遵循 `paper-research` 工作流：正文内容使用 `search_paper_library`，图、表或公式使用 `search_paper_elements`，然后用 `read_paper_section` 或 `read_paper_element` 验证选中的结果。
2. 数字、数据集、基线、公式、贡献和书目信息，只能使用已验证的本地证据和用户提供的项目材料。标题、检索候选、模型记忆或网页摘要都不是充分证据。
3. 技术表述应围绕清晰链条展开：研究对象 → 条件或影响 → 现有方法的局限 → 提出方法的动机 → 可用的验证证据。
4. 保留现有的 `\label`、`\ref`、`\cite`、数学环境、图、表和文档类约定。不要臆造实验，或把证据缺口悄悄润色成确定性表述。最终回复中将每个缺口列为 **Author checks** 项。
5. `paperagent-cite:E<n>` 是仅用于 DSH 对话的证据 token。绝不要将其、PDF 页码、PaperAgent 元素 id 或对话引用卡片写入 `.tex` 或 `.bib` 文件。

## 已验证的参考文献同步

1. 使用 `read_paper_bibliography` 获取选中论文的 id（最多 20 个）。只有同时满足 `metadataStatus: ready`、`citationKey` 非空且 `bibtex` 非空的条目，才允许同步。
2. 编辑前先读取目标 `.bib`。依次检查相同的引用 key、等价 DOI，以及规范化后的标题 + 作者 + 年份。已存在等价条目时直接复用，不得重复追加。
3. 如果相同引用 key 已存在但元数据不同，应停止并展示冲突。不要覆盖、删除、重命名或静默选择任一条目。
4. 对确认不重复的条目，使用 DSH 编辑工具仅追加该条目，同时保留文件现有的编码、换行、顺序和后端。不要重新格式化或重写整个参考文献文件。
5. 只有 `.bib` 更新成功后，才在用户批准的论断位置进行最小编辑，插入项目现有的引用语法，通常是 `\cite{citationKey}`。不要猜测插入位置；不要为了方便把 `\cite` 改成 `\citep`、`\autocite`、BibLaTeX 或其他后端语法。

## LaTeX 修复与验证

- 优先使用项目已有的构建命令、`latexmkrc`、CI 配置或用户提供的命令。如果没有，应报告候选命令并请求确认，不要猜测构建设置。
- 只能在当前工作区运行命令。绝不要使用 `-shell-escape`、安装软件包、修改文档类或替换参考文献后端。
- 允许构建后，检查相关 `.log` 输出中的编译错误、未解析引用、重复标签以及明显的 overfull/underfull box。如果生成 PDF，在可用时检查受影响的页面。
- 最终回复必须说明修改的文件、插入或复用的引用 key、编译结果、未解决风险以及 **Author checks**。如果没有获得文件修改授权，或无法安全确定目标，应提供建议补丁而不是修改文件。

## 简明工具顺序

| 用户意图 | 必须遵循的顺序 |
| --- | --- |
| 起草/润色且包含本地论文结论 | 读取目标 → `paper-research` 检索 → 验证章节/元素 → 最小编辑 |
| 添加本地引用 | 读取 `.tex`/`.bib` → 检索并验证证据 → `read_paper_bibliography` → 去重/冲突检查 → 编辑 `.bib` → 编辑 `\cite{}` |
| 修复 LaTeX | 读取源码/构建说明/日志 → 最小修改 → 运行已有且获准的构建 → 检查日志/PDF |
| 缺少证据、BibTeX、引用 key 或目标 | 安全停止并说明缺少的输入 |
